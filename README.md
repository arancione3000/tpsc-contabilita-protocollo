# TPSC / Contabilità — Protocollo personale

Repository privato con le istruzioni da applicare agli esercizi di **libro giornale, partita doppia e liquidazione IVA**.

## File principali

- **[`AGENTS.md`](AGENTS.md)** — prompt/protocollo completo e vincolante da leggere prima di svolgere gli esercizi.
- **[`piano-dei-conti.md`](piano-dei-conti.md)** — trascrizione del piano dei conti autorizzato delle pagine 588-589.
- **`riferimenti/`** — fotografie originali del piano dei conti.

## Workflow per l'assistente AI

Quando lo studente invia un esercizio:

1. leggere tutto l'esercizio;
2. recuperare e leggere integralmente `AGENTS.md` da questo repository;
3. consultare `piano-dei-conti.md` e, se necessario, le fotografie originali;
4. svolgere l'esercizio;
5. eseguire la checklist finale prima di consegnare.

Il repository è la **fonte canonica**: se le istruzioni vengono aggiornate qui, usare la versione più recente.
